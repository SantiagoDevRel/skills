# Streamable HTTP preflight

Use this only for an authorized endpoint and network request. An existing host connection is preferable. This procedure tests transport/discovery, not funding, SDK writes, service deployment or an entire profile. Keep credentials in the authorized client's secret storage; record method, status, request ID and negotiated version without headers, tokens or task text.

1. POST a JSON-RPC `initialize` request containing a supported protocol version, client capabilities and client information. Send `Content-Type: application/json` and `Accept: application/json, text/event-stream`. Accept either a JSON response or an SSE stream and parse its JSON-RPC response by request ID. Check the returned version and capabilities; stop if the version is unsupported. [Lifecycle specification](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle), [transport specification](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports).
2. Send `notifications/initialized` as a notification, without an ID. An accepted notification returns HTTP `202` with no body. Include `MCP-Protocol-Version` with the negotiated version on subsequent requests. If initialization returned `Mcp-Session-Id`, propagate it; if no session header was returned, do not invent one. A `404` for a previously established session requires a new initialization without that session ID. GET-based streaming is optional; HTTP `405` from GET alone does not mean POST initialization is broken. [Transport specification](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports).
3. Once initialized, call `tools/list` if the server advertises tools, and `prompts/list` if it advertises prompts. Follow every `nextCursor` by passing its value as `cursor`; a single page is not the complete catalog. Use the returned names and schemas rather than remembered counts or host prefixes. Annotations cannot establish confidentiality or authorization. Discovery success is separate from a successful task call. [Tool specification](https://modelcontextprotocol.io/specification/2025-06-18/server/tools), [prompt specification](https://modelcontextprotocol.io/specification/2025-06-18/server/prompts).

The retained Arkiv root capture was stateless, but session behavior must be discovered on the actual endpoint. No gateway call was performed for this reference. The linked protocol revision was checked on 2026-10-08; negotiate the version supported by both endpoints rather than assuming that revision is the server's current version.
